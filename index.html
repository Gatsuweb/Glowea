Questions Fréquentes

Est-ce que Glowéa est adapté si je travaille seule ? expand_more
Absolument. Glowéa a été conçu spécifiquement pour les indépendantes et les petites structures. Il agit comme votre assistant personnel, vous libérant du temps pour vous concentrer sur vos prestations.
Puis-je importer ma liste de clientes actuelle ? expand_more
Oui, l'importation de votre base de données clientes (depuis Excel ou un autre logiciel) est très simple. Notre équipe support est également disponible pour vous accompagner dans cette transition.
Comment fonctionnent les acomptes en ligne ? expand_more
Lorsqu'une cliente réserve en ligne, elle est invitée à régler un acompte (dont vous fixez le montant ou le pourcentage) via notre plateforme de paiement sécurisée. Le rendez-vous n'est confirmé qu'une fois l'acompte validé, réduisant ainsi les no-shows à presque zéro.
