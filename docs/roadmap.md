# Glowea Roadmap

## Objectif beta

Livrer une version utilisable par des professionnelles beaute avec :
- authentification ;
- clientes ;
- fiche cliente complete ;
- rendez-vous ;
- sessions techniques ;
- galerie ;
- historique ;
- responsive mobile/tablette ;
- securite multi-tenant.

## MVP prioritaire

- Stabiliser les erreurs TypeScript.
- Finaliser les tests manuels beta.
- Verifier tous les filtres `tenantId`.
- Verifier les flux Stripe Connect.
- Verifier notifications push/SMS.
- Completer documents juridiques.
- Auditer responsive mobile.

## Apres beta privee

- Ameliorer onboarding.
- Renforcer analytics produit.
- Ajouter exports donnees.
- Ajouter suppression compte.
- Etendre automatisations marketing.
- Ameliorer campagne email/SMS.
- Renforcer monitoring erreurs.

## Hors MVP

- Fonctionnalites avancees de CRM.
- Automatisations complexes.
- Marketplace.
- Multi-etablissement avance.
